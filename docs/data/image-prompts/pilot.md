# Image prompts: pilot (20 images covering 51 menu items)

One prompt per message in **ChatGPT**. Download each result and save it with the filename shown into `artifacts/dish-images/chatgpt/`. Use `artifacts/dish-images/gemini/` for any dish you regenerate in Gemini.

Then run `npm run images:ingest -- pilot` and open `artifacts/dish-images/pilot-compare.html`.

Tips: work one category at a time. If an image is square, ask for "4:3 landscape"; ingest crops to 4:3 either way. If a result is wrong, reply with the fix instead of starting over (for example, "make the dumplings crescent-shaped").
